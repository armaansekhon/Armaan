# Project screenshots

Drop 2–4 vertical app screenshots per project here. They cross-fade with a
Ken Burns drift inside the phone (stills that feel like video). Until present,
the phone shows a branded gradient fallback automatically.

Naming (slug = epic | randavu | bloom | estate):
  <slug>-1.jpg   <slug>-2.jpg   <slug>-3.jpg

Specs:
  - vertical phone screenshots, ~1080x2340 (9:19.5)
  - .jpg or .webp, < 300 KB each
  - a single image works too (Ken Burns only, no cross-fade)

Augerr has no screenshots (coming-soon teaser).
